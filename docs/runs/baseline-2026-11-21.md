# PearHost baseline — 2026-11-21

PearHost on macOS 27.2 (Apple silicon), runtime `194064a`. Each game is
prepared from its installed bundle with `tools/host-prepare.sh`, run for 20 s
in its own container copy, and only its window is captured. *launched*: our
UIKit reached `launch complete`; *rendered*: the captured window is not black;
*missing*: distinct API calls reported by the missing-call reporter.
